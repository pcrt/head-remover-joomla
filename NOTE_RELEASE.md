Head Remover 2.0.0 riscrive il plugin per Joomla 5 e 6: gestione degli asset con WebAssetManager, rimozioni per URL, JS/CSS ordinati, metadati e commento MOTD. Interfaccia italiana e inglese. GPL-2.0-or-later.

È una nuova installazione (`headremover`), distinta dalla 1.1.0 (`head_remover`). Migrazione manuale descritta nel README. La vecchia versione resta invariata.

Richiede PHP 8.1+ e i requisiti della versione Joomla utilizzata (PHP 8.3+ per Joomla 6). Disabilitare core o altre dipendenze può compromettere le funzioni del sito: provare prima su una copia.

Stato della verifica: build e controlli statici completati. Test funzionali Joomla 5.4/6.2, lint PHP 8.3 e JED Checker non eseguiti per restrizioni dell’ambiente di preparazione. La verifica runtime resta necessaria prima dell’uso in produzione.
